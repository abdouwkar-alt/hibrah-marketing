## 3. Required review for every image

Open each image in the GitHub folder and record one decision:

- **ACCEPT** — relevant, visually useful, and correctly categorized for the HIBRAH reference library.
- **REJECT** — irrelevant, unsuitable, poor quality, redundant, or misleading.
- **RECLASSIFY** — useful, but its category or descriptive label is incorrect.

For each image, record:
1. Image number and filename.
2. Decision: ACCEPT / REJECT / RECLASSIFY.
3. Short reason grounded in the visible image.
4. Correct category, if reclassified.
5. Whether it is an exact or near duplicate of another image.
6. Intended reference use (fabric, suit silhouette, fit, construction/detail, styling, complete outfit, etc.).

Do not mark an image ACCEPT solely because its filename or source page sounds relevant. Judge the actual image.

## 4. Items requiring particular attention

These are metadata-based flags, not completed visual judgments. Confirm them by opening the files:

- Images **29–30** are named as a navy/brown check cotton-silk two-pocket long-point item; verify whether they are shirts rather than suits and reclassify or reject accordingly.
- Images **35–36** are explicitly named as bleach-wash Japanese selvedge denim; these appear outside the suits category and should be rejected or reclassified if they have a justified reference use.
- Images **44** is only 512 × 512 pixels; assess whether its resolution and content provide meaningful reference value.
- The jacket-details category has only **1** image and trouser-details has only **2**; report the collection gaps rather than accepting weak images merely to fill categories.
- Check Drake's images for repeated product angles, near-duplicates, and campaign/editorial images that add no distinct reference value.

## 5. Separate rights review — mandatory

Creative approval does not equal rights clearance.

All 49 images currently have:
- `creative_review_status: PENDING`
- `rights_status: NOT_CLEARED`
- `intended_use: INTERNAL_CREATIVE_REVIEW_ONLY`

Do not change rights status during the Creative review unless the reviewer is separately authorized and has verified item-level usage terms. A separate rights review must establish the permitted use for each image.

## 6. Migration gates

Do not move the full folder to `main` as a batch.

1. Complete and save the item-level Creative review.
2. Remove rejected images from the proposed approved collection; retain a traceable record of the decision.
3. Correct categories and filenames for reclassified images.
4. Complete a separate item-level rights review.
5. Only images that pass both reviews may be considered for migration to `main`.
6. Upload to Canva only after the image has passed Creative review and rights clearance for the intended Canva use.

The repository is public, so rights-uncleared images must not be treated as approved assets or migrated into the approved library.
