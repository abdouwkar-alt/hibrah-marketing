## Collection and review rules

1. Each category target is 50 relevant, non-duplicate image candidates. Do not fill the quota with weak or off-topic images.
2. Record source page, direct image URL, source/brand, item description, dimensions, checksum, and category.
3. Separate visual review (ACCEPT / REJECT / RECLASSIFY) from rights clearance.
4. Canva upload is permitted for internal preview/review. It does not grant publication, redistribution, or campaign rights.
5. Preserve the current approved brand/operating documents. This collection tracker is a working record only.
6. Report actual uploaded counts and failed imports; never label a category complete until 50 items are present and verified.
