# HIBRAH — Fabric Reference Review (100 Images)

This batch is dedicated to wool and classic men's suiting cloth.

## Pipeline
1. Curate candidate source pages from specialist clothmakers and suiting-fabric retailers.
2. Download product images through GitHub Actions.
3. Validate image type, dimensions, size, and SHA-256 uniqueness.
4. Save image files, manifest, CSV, and contact sheets to the repository.
5. Complete visual review (description, category, quality, visible logo/watermark, duplicates, ACCEPT/REJECT/REVIEW).
6. Upload the reviewed image files to the dedicated Canva folder for Founder review.

## Current review status
The downloader leaves visual review fields as PENDING. A successful download is not a visual approval.
