# HIBRAH — Classic Menswear Reference Library

## Purpose
A structured internal reference library for classic menswear, tailoring, fabrics, footwear, accessories, fit, and styling. This is a research/reference library, not an automatically approved pool of campaign assets.

## Source policy
Every downloaded image must have a metadata record containing:
- local filename and category
- source provider and original page URL
- direct image URL where available
- creator/photographer when provided
- exact license name and license URL
- search query and retrieval date
- intended use: internal reference / campaign candidate / reference-only
- review status

Do not infer reuse rights from the ability to view or download an image. Check each individual asset's rights. Keep unknown, non-commercial, and no-derivatives assets out of campaign-candidate folders. CC BY requires attribution. CC BY-SA may impose share-alike obligations and should be reviewed before using derivatives in brand material.

## Source register
See `sources-register.json` for candidate providers, access methods, restrictions, and suitability.

## Quality rules
1. Search by category first, not by generic menswear terms.
2. Keep category folders semantically clean; do not accept unrelated images to reach a target count.
3. Avoid duplicate images and near-duplicates.
4. Store original source metadata alongside the image.
5. Separate historical/archival references from contemporary styling references.
6. Treat visual relevance as a separate check from copyright permission.
7. Do not use third-party images in HIBRAH advertising or public posts until the asset's license and any model/property/trademark restrictions have been reviewed.

## Initial workflow
Discover candidate sources -> search one category at a time -> filter by license -> download a small batch -> classify -> review image relevance -> retain or reject -> expand the batch.
