# الصلاة جامعة — iOS

هذه بداية مستقلة لنسخة iOS باستخدام SwiftUI، وليست تحويلًا آليًا لملفات Android/Kotlin.

## الحالة الحالية

- إعداد اتجاه الواجهة من اليمين إلى اليسار.
- هيكل أولي للتنقل بين الصلاة والقضاء والإحصائيات والإعدادات.
- نموذج أولي لتسجيل حالة الصلوات اليومية.
- نموذج أولي لعدادات القضاء.
- النص القرآني في شاشة القضاء مضبوط بعلامات اتجاه RTL حول الآية لتفادي انقلاب الأقواس.

## ما لم يكتمل بعد

هذه ليست نسخة iOS جاهزة للتثبيت أو النشر. يلزم نقل واختبار وظائف Android الأساسية، ومنها مواقيت الصلاة وحساب القضاء، التنبيهات، الأذكار والأدعية، السنن والفقه، تدبر القرآن والقارئ، الإحصائيات، والنسخ الاحتياطي.

## متطلبات البناء

يلزم جهاز Mac عليه Xcode لبناء التطبيق واختباره على محاكي iPhone أو جهاز فعلي، ثم إعداد التوقيع والتوزيع. لم يتم إجراء build أو اختبار iOS بعد.
