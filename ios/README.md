# الصلاة جامعة — iOS

مشروع SwiftUI مستقل. يتم بناء نسخة محاكي iPhone تلقائيًا عبر GitHub Actions على خوادم macOS/Xcode، دون الحاجة إلى جهاز Mac لدى صاحب المشروع.

## بناء المحاكي

- افتح تبويب Actions في GitHub.
- اختر iOS Simulator Build.
- بعد نجاح التشغيل، نزّل artifact باسم `salati-ios-simulator`.
- يحتوي الملف على تطبيق محاكي iOS بصيغة `.app` مضغوطة.

## حدود هذه النسخة

هذه نسخة محاكي وليست IPA قابلة للتثبيت مباشرة على iPhone. تثبيت التطبيق على جهاز حقيقي أو توزيعه عبر TestFlight يحتاج توقيعًا وشهادات وملفات provisioning مرتبطة بحساب Apple Developer وأجهزة الاختبار عند استخدام التوزيع Ad Hoc.

النسخة الحالية هي هيكل أولي. نقل الوظائف الكاملة من Android ما زال قيد التنفيذ، ويجب اختبارها قبل وصفها بأنها جاهزة للمستخدمين.
