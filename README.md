# صلاتي | Salati

تطبيق Android عربي لمتابعة قضاء الصلاة والصيام، مواقيت الصلاة، السنن الرواتب والأذكار اليومية.

## البناء
يُبنى Debug APK تلقائيًا عبر GitHub Actions عند الدفع إلى فرع `salati-app`. افتح تبويب Actions ثم نزّل artifact باسم `salati-debug-apk`.

## المحتوى الشرعي
يفصل التطبيق بين السنن الرواتب المؤكدة، والأذكار الثابتة، والآداب. يعرض تصنيف السنن الرواتب وفق المشهور في المنهج الحنفي المصري؛ وتوجد اختلافات معتبرة بين المذاهب في عدد بعض الرواتب وتوصيفها. راجع المصادر المذكورة داخل التطبيق، ولا يُعد التطبيق جهة إفتاء.

## مواقيت الصلاة والتنبيهات
يستخدم التطبيق الموقع الحالي عند فتحه، ويعيد جدولة التنبيهات للأيام الثمانية التالية. طريقة حساب المواقيت الحالية تقريبية وتحتاج مقارنة بالتقويم الرسمي المحلي قبل الاعتماد. قد تؤثر أذونات الإشعارات والمنبهات الدقيقة وإدارة البطارية في عمل التنبيهات.

## الخصوصية
الموقع وأرقام المتابعة محفوظة محليًا على الجهاز ولا تُرسل إلى خادم.
