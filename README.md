# صلاتي | Salati

تطبيق Android عربي لتسجيل قضاء الصلاة والصيام والتنبيه بمواقيت الصلاة.

هذه نسخة أولية قيد الاختبار. حساب المواقيت الحالي تقريبي (الفجر 19.5° والعشاء 17.5°) وليس اعتمادًا رسميًا من جهة الإفتاء أو هيئة المساحة. قارن الأوقات بتقويم محلي موثوق قبل الاعتماد عليها.

يبنى Debug APK تلقائيًا عبر GitHub Actions عند الدفع إلى فرع salati-app أو تشغيل workflow يدويًا. نزّل الملف من تبويب Actions ثم Artifacts.

يحتاج التطبيق إلى إذن الموقع والإشعارات. قد تؤخر إدارة البطارية في بعض أجهزة Android التنبيهات، وقد يتطلب التنبيه الدقيق تفعيل إذن المنبهات الدقيقة من إعدادات النظام.

الموقع وأرقام المتابعة محفوظة محليًا على الجهاز. أرقام القضاء الابتدائية تقديرية أدخلها المستخدم، والتطبيق أداة تسجيل فقط وليس فتوى.
